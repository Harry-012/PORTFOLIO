E-Commerce Sales Forecasting Platform END-TO-END ML
Production-style system

A production-style demand forecasting pipeline for e-commerce inventory planning, processing 540K+ transaction records into daily per-product forecasts.

  • Modular pipeline with time-series feature engineering (lag/rolling-window features, seasonality flags), split into independent, testable Python modules.
  • Trained a CatBoost regression model with chronological train/test splitting to prevent data leakage — a 32% reduction in mean absolute error vs. a naive baseline.
  • FastAPI REST backend with prediction, product-history, and health-check endpoints, plus a custom-styled Streamlit dashboard for non-technical users.
  • Lightweight model monitoring with prediction logging and automated drift detection.
  • Deployed API + dashboard as independent services on Render via GitHub-integrated CI/CD; automated tests (pytest) for the data pipeline.
